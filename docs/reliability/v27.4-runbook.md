# v27.4 Reliability Runbook

## Automatic path

1. Telemetry reports a failure.
2. Reliability classifies severity and impact.
3. State protection runs before recovery.
4. A bounded retry is attempted.
5. Health is verified.
6. The service resumes only after verification.
7. Failed verification triggers an approved rollback path or escalation.

## Human approval

Approval is required for security-sensitive, financial, external, data-loss, destructive, or high-severity recovery actions.

## Operational rule

Do not treat a retry as a successful recovery. A recovery is successful only after verification passes.

## Audit

Every recovery attempt should emit telemetry containing the correlation ID, component, failure category, attempt number, selected stage, result, and approval reference when applicable.
